### Adatvédelem

A játékok nem gyűjtenek adatot: nincs regisztráció, analitika, süti, hirdetés vagy követés, és a játék semmit nem küld el sehova. Az állás és a rekord csak a böngésződben marad (`localStorage`), a böngésző adatainak törlésével eltűnik. A betűtípusok a saját oldalról töltődnek (`assets/fonts/`). Kivétel a Falbontó, a Kincsvadász és a Betűbánya néhány betűtípusa (Audiowide, Press Start 2P, VT323), ezeket a Google Fonts szolgáltatja, így ennél a három játéknál a betöltéskor a Google látja a látogató IP-címét.

A startlap tetején kereső van (név és leírás szerint, ékezet nélkül is, magyarul és angolul), alatta a **Kedvencek** polc: minden kártya alján a ☆ Kedvenc gombbal legfeljebb 10 játék tehető ide, abban a sorrendben, ahogy csillagozod. Utána a **Folytatás** polc a legutóbb megnyitott 3 játékkal. Ezek a listák is csak a böngészőben maradnak (`localStorage`).

Az akciójátékok kontrollerrel (gamepad) is játszhatók gépen és Androidon: a kar vagy a d-pad mozgat, az A gomb lő vagy ugrik, a Start szünetet tart, menüben a kar a gombok között lép, az A megnyomja a kijelöltet. iPhone-on a böngésző ezt nem támogatja.

Minden oldal Content-Security-Policy szabályt hordoz, így a böngésző maga tiltja le, ha egy oldal mégis más helyre próbálna kérést küldeni.

**Internet nélkül:** a startlap első megnyitásakor a böngésző eltárolja az oldal saját fájljait (startlap, játékok, betűtípusok, borítóképek; a `sw.js` service worker). Utána a startlap és minden játék internet nélkül is indul, telefonon a kezdőképernyőre is tehető. Más helyről semmit nem tárol és nem kér le. Ha új változat jelenik meg, a startlap alján egy **Frissítés** gomb kínálja fel; addig a régi marad. A Cornhole pontozónak ehhez saját service workere van.

A startlap kártyáin a játékból készült kis borítókép látszik (`assets/covers/`).

Futtatás helyben: nyisd meg a gyökérben lévő `index.html`-t, vagy egy játék mappájában lévő `index.html`-t a böngészőben.

### Új játék hozzáadása

1. Hozz létre egy mappát (pl. `uj-jatek/`), benne egy `index.html`-lel.
2. A `<head>`-be tedd be a startlap kártyájához:
   ```html
   <title>Játék neve</title>
   <meta name="description" content="Rövid magyar leírás">
   <meta name="games:category" content="jatek">        <!-- vagy: minecraft -->
   <meta name="games:title-en" content="English name">
   <meta name="games:description-en" content="Short English description">
   ```
3. Készíts borítóképet: `python3 tools/make_covers.py uj-jatek` (az `assets/covers/uj-jatek.webp` lesz, nézd meg, és ha rossz pillanatot fotózott, állítsd be a szkript `SHOTS` táblázatában).
4. Push a `main` ágra. A GitHub Actions újraépíti a startlapot és közzéteszi az oldalt. Ha a játékban nincs „← Összes játék” gomb, a közzétételkor automatikusan kap egyet. Közzétételkor minden oldal oldalikont és megosztási adatokat (`og:title`, `og:image`) kap, az offline tár (`sw.js`) pedig megkapja a fájllistát.

Helyben a listát a `python3 tools/build_site.py` frissíti a startlapon. Commit előtt kötelező a `python3 tools/build_site.py --check` és a `python3 tools/smoke_test.py`. A szabályokat az [AGENTS.md](AGENTS.md) írja le, a fejlesztő MI-ügynökök ezt követik.

### Tesztek

Minden push és pull request előtt lefut, és a közzététel csak akkor indul, ha minden zöld:

- **Minden játék** (`tools/play_test.py`): betölt, elindul és játszható gépen (billentyű, egér) és telefonon (érintés) szkripthiba nélkül; nem kér le semmit más oldalról; telefonon nincs oldalra görgetés; sérült, kézzel átírt vagy rossz alakú mentéssel sem omlik össze.
- **Valódi játékmenetek** (ugyanott): minden játékban egy-egy rövid, értelmes részt végigjátszik, és az eredményt is ellenőrzi (fizetés, szállítás, küldetés, pálya teljesítése, életvesztés, játék vége, mentés újratöltés után, tanári PIN, némítás, fekvő telefon, csökkentett mozgás).
- **Pályagenerátorok** (ugyanott): a Gyémántbánya és a Kincsvadász generátora több száz véletlen pályát készít, mindegyiknek érvényesnek és pontosan egy megoldásúnak kell lennie (független megoldóval ellenőrizve). A Dobozmester mind a 44 pályájáról egy megoldó igazolja, hogy megoldható. A Pasziánsz leosztásait változatonként több tucat mintán végigjátssza a megoldó, és minden lépésről ellenőrzi, hogy szabályos.

Mellette fut a telefonos füstteszt (`tools/smoke_test.py`, 400×860 és 360×640 méretben: nem takar el semmit a felső sáv, minden gomb elérhető és legalább 44×44 px), a szabályellenőrzés (`tools/build_site.py --check`) és a Cornhole pontozó szabálytesztjei (`cd cornholescore && node --test`).

Helyben: `pip install playwright && python3 -m playwright install chromium`, majd `python3 tools/play_test.py` (gyorsabban: `--quick`, egy játék: `python3 tools/play_test.py horda`).

## English

Single-file HTML games and Minecraft build plans that run in the browser. The start page (`index.html`) is published on GitHub Pages and lists every game in the repository automatically.

The games themselves are in Hungarian. See the table above for the list. Bike Shop, Downhill, Farm Empire, Arena, Dungeon, Invasion, Brawl, Horde and Trap are made for slow, reluctant teenage readers with dyslexia: large readable type, short words, long compound words split into coloured parts, and a read-aloud helper.

**Privacy:** the games collect no data: no sign-up, analytics, cookies, ads or tracking, and nothing is sent anywhere. Progress and records stay in your browser (`localStorage`). Typefaces load from this site (`assets/fonts/`), except three in Falbontó, Kincsvadász and Betűbánya (Audiowide, Press Start 2P, VT323), which come from Google Fonts; for those three games Google sees the visitor's IP address when they load.

**Search, Favourites, Continue:** the start page has a search box (names and descriptions, accents optional, Hungarian and English), then a Favourites shelf: tap ☆ Favourite at the bottom of any card to add up to 10 games, kept in the order you star them. A Continue shelf shows the last 3 games you opened. Both lists stay only in your browser (`localStorage`). The action games also work with a game controller on desktop and Android (stick or d-pad moves, A fires or jumps, Start pauses, menus are navigated with the stick). Every page carries a Content-Security-Policy, so the browser itself blocks any request to another site.

**Offline:** the first visit to the start page stores the site's own files (start page, games, fonts, cover pictures) with a service worker (`sw.js`); after that the start page and every game also open without internet, and the site can be added to a phone's home screen. Nothing from other sites is stored or requested. A new version is offered with an **Update** button at the bottom of the start page. The cards show a small cover picture of each game (`assets/covers/`).

**Adding a game:** create a folder with an `index.html`, add the `<head>` tags shown above, make a cover picture with `python3 tools/make_covers.py <folder>`, and push to `main`. The GitHub Actions workflow rebuilds the start page and deploys the site. Pages without a back button get one added on deploy.

**Tests:** every push and pull request runs browser tests (Playwright) on every game, desktop and touch, including broken saved data and checks that nothing is requested from other sites; scenario tests that play part of each reading game and check the result; and a regression test that generates hundreds of Gyémántbánya and Kincsvadász levels and checks each has exactly one solution. The site is deployed only when all tests pass. Run locally with `pip install playwright && python3 -m playwright install chromium`, then `python3 tools/play_test.py`.

**Minecraft:** the build plan pages only describe blocks and building steps, drawn by the page itself (no logo, textures or characters). Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft. Minecraft is a trademark of Mojang AB.

Self-hosted fonts are under the SIL Open Font License (`assets/fonts/LICENSE-*.txt`).

All code, games and text in this repository were created entirely by AI (Claude, Anthropic) and reviewed by another AI.
